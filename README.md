# Insurance Intelligence | Executive Analytics Dashboard

### Interactive Insurance Analytics & Business Intelligence

An interactive Tableau dashboard designed to explore insurance portfolio performance, analyze premium trends, compare agent performance, and support data-driven business decisions.

The project demonstrates how raw insurance data can be transformed into meaningful KPIs and interactive visualizations.

**[View Live Interactive Dashboard](https://public.tableau.com/views/InsuranceIntelligenceExecutiveAnalytics/INSURANCEINTELLIGENCE)**

## Project Overview

This dashboard provides an executive-level overview of insurance business performance using a synthetic dataset containing 3,600 insurance policies.

Users can interact with charts, apply product filters, compare performance across years, and explore individual agent results.

## Key Features

- **Executive KPIs:** Total Premium, Total Policies, Total Commission, and Renewal Rate.
- **Monthly Premium Trends:** Analyze premium performance over time.
- **Yearly Product Comparison:** Compare insurance products across multiple years.
- **Agent Performance Analysis:** Identify and compare agents based on total premium.
- **Interactive Filtering:** Explore performance by insurance product and selected chart categories.
- **Risk Segmentation:** Explore insurance policy risk categories in a separate worksheet.

## Dataset

The project uses **3,600 synthetic insurance policy records** covering 2024–2026.

The dataset includes insurance products, policy dates, premiums, commissions, agent identifiers, renewal statuses, and risk indicators.

**Data Privacy:** All data is synthetic and created for demonstration purposes. No real customer information or confidential company data is used.

## Business Value

The dashboard supports several key analytical questions:

- How does total premium change over time?
- Which insurance products contribute the most premium?
- How does agent performance compare?
- What proportion of policies are renewed?
- How can interactive filtering help identify performance patterns?
